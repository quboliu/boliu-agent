## 第 7 章——内存

问：使用 Linux 术语，分页和交换之间有什么区别？

答： 分页是内存页的移动；交换是页面往返于交换设备/文件的移动。

问：描述内存利用率和饱和度。

答：对于内存容量，利用率是已占用、无法再供分配的内存量占可用内存总容量的比例。与文件系统容量类似，它可以表示为百分比。饱和度衡量的是内存需求超出内存容量的程度；这通常会触发内核例程释放内存，以满足这些需求。

## 第 8 章—文件系统

问：逻辑 I/O 和物理 I/O 有什么区别？

答：逻辑 I/O 面向文件系统接口；物理 I/O 面向存储设备（磁盘）。

问：解释文件系统写时复制如何提高性能。

答：由于随机写入可以写入新位置，因此可以将它们分组（通过增加 I/O 大小）并按顺序写出。这两个因素通常都会提高性能，具体取决于存储设备类型。

## 第 9 章—磁盘

问：请描述当磁盘工作超载时会发生什么情况，包括对应用程序性能的影响。

答： 磁盘持续高利用率（高达 100%）运行，且饱和度高（排队）。由于排队的可能性（可以建模），它们的 I/O 延迟会增加。如果应用程序正在执行文件系统或磁盘 I/O，则增加的延迟*可能*会损害应用程序性能，前提是它是同步 I/O 类型：读取或同步写入。它还必须发生在关键应用程序代码路径期间，例如在处理请求时，而不是异步后台任务（这可能只会“间接”导致应用程序性能不佳）。通常，由于 I/O 延迟增加而产生的背压会控制 I/O 请求的速率，并且不会导致延迟无限增加。

## 第 11 章—云计算

问：描述从操作系统级虚拟化的容器实例中观测物理系统的情况。

答：根据宿主机内核的实现，容器可以看到所有物理资源（包括 CPU 和磁盘）的高级指标，并能察觉其他租户何时在使用这些资源。内核应屏蔽会泄露用户数据的指标。例如，可以观测到 CPU 利用率（如 50%），但看不到造成该利用率的其他租户的进程 ID 和进程名称。
